# Franklyn’s Baby Supplies concept

Source export for the current website concept. This is a Next.js application using the Vinext development and build tooling.

## Run locally

- Install Node.js 22.13 or later and pnpm 11.25.
- Run `pnpm install`.
- Run `pnpm dev` and open the local address shown in the terminal.

## Repository

Extract this ZIP, then add the extracted files to a new GitHub repository. The original Sites hosting configuration and local build output are excluded from this export.

The current site is a product concept. Catalogue interactions and ordering flows are for demonstration; a production payment integration, order fulfilment and a connected commerce database still need to be implemented. The included `db/schema.ts` is starter scaffolding, not a complete PostgreSQL e-commerce schema.
